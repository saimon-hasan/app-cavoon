# First-version demo walkthrough

This is a functional walkthrough for the mobile prototype, not the full JULIETT presentation.

1. Open Discover and tap Explore the collection.
2. Search for Oxford. Show the one matching product.
3. Open Classic Oxford Shirt and try Add to bag before choosing a size. Show the helpful validation message.
4. Choose Light blue and M. Save the piece using the heart, then add it to the bag.
5. Open the bag. Increase quantity to two. The subtotal should be $130.00.
6. Restart the app (or reload the browser preview). Confirm the selected variant, quantity, and subtotal remain.
7. Open Saved and show the same shirt.
8. Open Review your selections. Explain that this version saves a bag but does not place an order.
9. Show the state/persistence thread described in `architecture.md`.

Before presenting: load photos while connected, clear any earlier demonstration items, rehearse on the target device, and retain a short recording as a fallback.
